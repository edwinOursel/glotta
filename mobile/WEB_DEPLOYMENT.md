# 🌐 Flutter Web Deployment Guide

This guide explains how to build and deploy the Glotta mobile app as a web application that runs in browsers (desktop & mobile).

## 🎯 Why Flutter Web?

The **same Dart code** runs as:
- 📱 Native Android app
- 🍎 Native iOS app
- 🌐 **Web app** (this guide)
- 💻 Desktop app (Windows/macOS/Linux)

Perfect for:
- Testing on Termux (where native Flutter dev is hard)
- Accessing from any device with a browser
- PWA (installable like a native app)
- Quick prototyping

## 🏗️ Building for Web

### Prerequisites

- Flutter SDK installed (on PC/Mac, not Termux)
- Or use GitHub Codespaces / cloud IDE

### Build Steps

```bash
# 1. Navigate to mobile directory
cd mobile

# 2. Get dependencies
flutter pub get

# 3. Build for web (production)
flutter build web

# 4. Output will be in: build/web/
```

**Build options:**

```bash
# Development build (faster, includes debug info)
flutter build web --debug

# Release build (optimized, smaller)
flutter build web --release

# With custom base URL
flutter build web --base-href /glotta/

# Enable web renderer (better performance on mobile)
flutter build web --web-renderer canvaskit
# or for smaller size:
flutter build web --web-renderer html
```

## 🚀 Deployment Options

### Option 1: Local Testing (Termux-friendly!)

Perfect for testing on your Android device via Termux:

```bash
# After building on PC, copy build/web/ to your device

# In Termux, from the mobile/ directory:
python serve_web.py

# Open browser to: http://localhost:8080
```

The Python server script:
- Serves the static files
- Sets correct MIME types
- Enables CORS for API calls
- Works on any port

### Option 2: Static Hosting (Free)

Deploy to free static hosting services:

**GitHub Pages:**
```bash
# 1. Build
flutter build web --base-href /glotta/

# 2. Copy build/web/ contents to gh-pages branch
cp -r build/web/* ../gh-pages/

# 3. Push
cd ../gh-pages
git add .
git commit -m "Deploy web app"
git push

# Available at: https://username.github.io/glotta/
```

**Netlify:**
```bash
# 1. Build
flutter build web

# 2. Deploy via Netlify CLI
npm install -g netlify-cli
netlify deploy --dir=build/web --prod

# Or drag-and-drop build/web/ folder on netlify.com
```

**Vercel:**
```bash
# 1. Build
flutter build web

# 2. Deploy
npm install -g vercel
cd build/web
vercel --prod
```

**Firebase Hosting:**
```bash
# 1. Install Firebase CLI
npm install -g firebase-tools

# 2. Initialize
firebase init hosting

# 3. Configure firebase.json:
{
  "hosting": {
    "public": "build/web",
    "ignore": ["firebase.json"],
    "rewrites": [{
      "source": "**",
      "destination": "/index.html"
    }]
  }
}

# 4. Deploy
flutter build web
firebase deploy
```

### Option 3: Self-Hosted Server

Deploy on your own server:

**Nginx:**
```nginx
server {
    listen 80;
    server_name glotta.example.com;

    root /var/www/glotta;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # Enable gzip compression
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
}
```

**Apache:**
```apache
<VirtualHost *:80>
    ServerName glotta.example.com
    DocumentRoot /var/www/glotta

    <Directory /var/www/glotta>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted

        # SPA routing
        RewriteEngine On
        RewriteBase /
        RewriteRule ^index\.html$ - [L]
        RewriteCond %{REQUEST_FILENAME} !-f
        RewriteCond %{REQUEST_FILENAME} !-d
        RewriteRule . /index.html [L]
    </Directory>
</VirtualHost>
```

## 📱 Progressive Web App (PWA)

The app is already configured as a PWA with:
- ✅ Web manifest (`web/manifest.json`)
- ✅ Service worker (auto-generated by Flutter)
- ✅ Installable on mobile/desktop
- ✅ Works offline (once cached)

**To install:**
1. Open the web app in browser
2. Look for "Add to Home Screen" (mobile)
3. Or "Install" button in address bar (desktop)
4. App launches like a native app!

## 🔧 Configuration

### API Base URL

The app needs to connect to the backend API. Configure in two ways:

**1. Environment variable (build time):**
```bash
# Set backend URL before building
export API_BASE_URL=https://api.glotta.example.com
flutter build web
```

**2. Runtime configuration:**
```dart
// In lib/services/api_service.dart
ApiService(
  baseUrl: const String.fromEnvironment(
    'API_BASE_URL',
    defaultValue: 'http://localhost:8000',
  ),
)
```

**3. Settings page:**
Users can change API URL in app settings.

### For Termux Testing

If running both backend and frontend locally:

```bash
# Terminal 1: Backend
cd core
uv run python api_server.py
# Runs on http://localhost:8000

# Terminal 2: Frontend
cd mobile
python serve_web.py 8080
# Runs on http://localhost:8080

# Open browser: http://localhost:8080
# API calls go to: http://localhost:8000
```

## 🐛 Troubleshooting

### CORS Issues

If you get CORS errors when calling the API:

**Backend fix (api_server.py):**
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # Or specify your domain
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### White Screen

- Check browser console for errors
- Ensure `flutter.js` is loaded
- Verify base href matches deployment path
- Try different web renderer (canvaskit vs html)

### Large File Size

Optimize the build:

```bash
# Use HTML renderer (smaller but less features)
flutter build web --web-renderer html

# Enable tree shaking
flutter build web --dart-define=dart.vm.product=true

# Profile the bundle
flutter build web --analyze-size
```

### Mobile Performance

For better mobile experience:

```bash
# Use CanvasKit for smooth animations
flutter build web --web-renderer canvaskit

# Or auto (Flutter chooses best renderer)
flutter build web --web-renderer auto
```

## 📊 Build Output

After `flutter build web`, the `build/web/` directory contains:

```
build/web/
├── index.html          # Entry point
├── main.dart.js        # App code (minified)
├── flutter.js          # Flutter engine
├── manifest.json       # PWA manifest
├── favicon.png         # Icon
├── icons/              # PWA icons
├── assets/             # Images, fonts, etc.
└── canvaskit/          # Rendering engine (if used)
```

Total size: ~2-5 MB (gzipped: ~500KB - 1MB)
